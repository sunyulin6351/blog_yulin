# 雨林说

雨林说（<https://blog.yulin.ltd/>）是雨林的个人博客。

我把生活当作一个长期实验项目，用系统思维拆解问题，用小规模试验验证想法，记录每一次迭代的过程。从时间管理到身体训练，从知识输入到表达输出，我希望一点点搭建属于自己的"人生操作系统"。

长文按「想回答什么问题」分成三类：**人生系统**、**技术思考**、**生活实验**。三个分类之外还有一条「想法」流，记录一句话的观察、灵感和日常瞬间。
